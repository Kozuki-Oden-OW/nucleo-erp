Code signing policy

Política de firma de código

Última actualización: 10 de octubre de 2026.

Los instaladores de NÚCLEO ERP para Windows se compilan automáticamente desde el código fuente público del repositorio oficial con GitHub Actions. Ninguna persona compila ni modifica el instalador a mano.

Firma

Hemos solicitado firmar los instaladores con un certificado de firma de código gratuito para proyectos de código abierto: el servicio de firma lo provee SignPath.io y el certificado, la SignPath Foundation. Mientras la solicitud se aprueba, las versiones se publican sin firma y con su huella SHA-256 en la página de descarga. Cuando la firma esté activa, cada versión firmada lo indicará en sus notas de publicación.

Equipo y roles

  • Autores (pueden modificar el código): Kozuki-Oden-OW.
  • Revisores (revisan los cambios de personas externas antes de integrarlos): Kozuki-Oden-OW.
  • Aprobadores (aprueban cada solicitud de firma de una versión): Kozuki-Oden-OW.

Todas las cuentas del equipo usan autenticación de dos factores. Cada versión se aprueba manualmente antes de firmarse.

Qué se firma

  • Solo los instaladores de NÚCLEO ERP construidos desde este repositorio, con nombre de producto y versión en sus propiedades.
  • No se firman programas de terceros. Las bibliotecas de código abierto que NÚCLEO usa se incluyen tal como las publican sus autores.

Privacidad

Este programa no transfiere ninguna información a otros sistemas en red a menos que el usuario o la persona que lo instala lo solicite expresamente. Detalles en la política de privacidad.

Cómo verificar tu descarga

  1. Descárgalo solo desde www.nucleoerp.cl/descargar o desde las versiones del repositorio.
  2. Compara su SHA-256 con el publicado: en PowerShell, Get-FileHash .\NucleoERPSetup.exe -Algorithm SHA256.
  3. Cuando esté firmado: clic derecho en el archivo → Propiedades → Firmas digitales.
